# Black-DOLPHIN
Portage Dolphin (GameCube) → PS3


Projet : émulateur Dolphin réduit (GameCube only) sur PlayStation 3 via PSL1GHT / ps3dev
Machine hôte : Windows 10 (build 17763) + WSL
Date de démarrage : 2026-11-09
Scope : GameCube uniquement (Wii hors scope)
Objectif

Faire tourner un core Dolphin minimal sur PS3 homebrew :

    CPU : interpréteur PowerPC (pas de JIT x64/ARM)
    GPU : software d’abord, RSX plus tard
    UI : NoGUI
    Cible : preuves de concept / jeux GC très légers
